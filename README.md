# Student Budget Tracker

## Project Overview

Student Budget Tracker is a simple Python-based console application designed to help students manage their monthly budget and daily expenses.

The program allows users to set a monthly budget, record expenses, view spending details, search expenses, and analyze their spending habits.

## Features

* Set a monthly budget
* Add new expenses
* View all recorded expenses
* Delete an expense
* Search expenses by title, category, or date
* View total spending
* View remaining budget
* Calculate average expense
* Find the highest expense
* View category-wise spending
* Calculate percentage of budget used
* Display budget usage warnings
* Automatically save expense data
* Load previously saved data

## Technologies Used

* Python
* Object-Oriented Programming
* JSON file handling
* Exception handling
* Lists and dictionaries
* Functions and classes
